# 📌 명명은 어떻게 담론이 되는가

> **'MZ세대'를 둘러싼 뉴스 프레이밍과 댓글 담론의 통합 분석**

본 프로젝트는 사회적 명명(Naming)인 'MZ세대'가 언론 및 대중 담론 내에서 어떻게 규정되고 확산되는지 다각도로 검증하는 데이터 분석 플랫폼 구축 프로젝트입니다.

하나의 **메인 프로젝트**와 두 개의 **서브 프로젝트**로 구성되어 연구 분석과 데이터 검증 도구를 통합 제공합니다.

## 📂 Sub-Projects Detail

### 1. 🎯 메인 프로젝트

**뉴스 기사의 MZ세대 프레이밍 분석 — 인간 라벨링과 AI 라벨링의 이중 접근**

* **개요**: 주요 언론사 뉴스 기사 데이터를 수집하여 'MZ세대' 관련 보도 프레임을 다각도로 분석합니다.
* **핵심 기능**:
* 인간 라벨링 데이터와 AI(LLM) 자동 라벨링 결과를 교차 검증하여 교차 검증도(Inter-annotator Agreement) 확보
* 긍정/부정/중립 프레이밍 및 주요 공통 키워드 패러다임 분류



### 2. 🛠️ 서브 프로젝트 1

**AI 라벨링(댓글 담론 분석) 및 Word2Vec 의미 분석 툴**

* **개요**: 뉴스 댓글 데이터를 수집하여 대중의 실제 담론 및 반응 패턴을 정밀 분석하는 가공·시각화 도구입니다.
* **핵심 기능**:
* 댓글 데이터에 대한 AI 기반 자동 감정 및 담론 라벨링
* Word2Vec 모델을 활용한 'MZ세대' 핵심 연관어 임베딩 공간 탐색 및 근연도(Similarity) 시각화



### 3. 🌐 서브 프로젝트 2

**데이터 상호검증·공유 플랫폼 'VeriData Hub'**

* **개요**: 분석에 활용된 데이터셋, 라벨링 결과, 유사도 분석 파일(.xlsx)을 공유하고 사용자 간에 반론과 검증을 제기할 수 있는 아카이브 플랫폼입니다.
* **핵심 기능**:
* 엑셀 기반 분석 결과 업로드 및 자동 메타데이터/워드클라우드 추출
* 게시글 기반 분석 공유 및 사용자 추천 기반 반론(Rebuttal)·검증 기능 제공
